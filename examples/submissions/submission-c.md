A list is like an array. Once you create a list you cannot change it, so if you need to add items you have to make a new list. A dictionary is different because it can be changed, and it has no order at all, the items come out randomly.

I would use a list to store the days of the week since they never change. I would use a dictionary for a shopping cart where the item is the key and the quantity is the value, because the quantities change as the customer shops and I can update `cart["milk"]` directly.

So the main difference is that lists are fixed and dictionaries can be edited.
