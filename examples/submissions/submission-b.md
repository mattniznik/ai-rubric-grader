Lists and dictionaries both hold more than one value. A list keeps items in order and you use an index number to get them, for example `songs[0]` gives the first song. You can add to the end with `append`.

Dictionaries use keys instead of numbers. Each key points to a value, so `stock["apples"]` would give how many apples are left.

An example of a list is a playlist, because songs play in order and you move through them one at a time. Overall both are useful and which one you use depends on the program.
